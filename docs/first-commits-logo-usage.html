This artifact documents practical usage for the current First Commits utility mark and wordmark system. It is an internal reference file, not a production asset bundle.

01 / Status

Logo System Read

Current mark

Use the existing FC tile as the source mark.

The canonical file is public/fc-logo.svg. Use that asset for favicon, avatar, badge, event signage, and compact UI. Do not recreate it with live text or approximation shapes.

Extension direction

Build provenance language around the existing mark.

Keep the current tile as the logo. Add distinctiveness through nearby systems: commit IDs, diff lines, build-log labels, member stamps, and first-repo metadata.
