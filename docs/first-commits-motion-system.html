Reference only / motion direction

Motion should clarify the room, not perform.

First Commits motion should make the experience feel live, calm, and intentional. Use movement to reveal priority, explain progress, and create depth around people and events.

02 / Principles

Movement rules.

Motion should be useful enough that removing it would make the interface feel less clear, not just less decorated.

Hierarchy

Move the next decision first.

Use motion to rank what the visitor should notice, read, or act on.

Restraint

One active idea per viewport.

Background movement must stay slower than the reader.

Continuity

Motion connects sections.

Parallax should help the page feel physically continuous as users scroll.

Access

Reduced motion is first class.

Every animated pattern needs a calm, complete still-state fallback.

03 / Timing

Speed tokens.

Keep timings tight for controls and slower for spatial depth. Nothing in the product should feel like a splash screen.

120-180ms Micro feedback

Buttons, inputs, hover states, pressed states, and active tabs.

220-320ms Content reveal

New form fields, validation summaries, cards, and lightweight panels.

500-900ms Spatial depth

Hero layers, editorial parallax, room signage, and event compositions.

0ms Critical correction

Errors, destructive confirmations, and submit disabled states appear immediately.

04 / Scroll

Parallax choreography.

Use sticky stacking for high-signal pages: homepage story beats, event pages, application review, and partner proof.

Recommended scroll pattern

One layer locks while the next one arrives.

This gives the brand depth without creating a noisy background. Content still owns the page; motion is the pacing layer.

Step 01

Founding engineer story.

Reveal the premise with a single large editorial line.

Step 02

Proof of room.

Application moment.

Step 04

End with a stable call to action, not another flourish.

05 / Interaction

Controls move less.

Interactive states should feel responsive and precise. Keep form and navigation motion short so the product still feels serious.

Button
Request invite

Translate up 2px, change color, no bounce.

Input focus

Use citrine as a focus ring, never as a full form surface.

Toast
Application saved for review.

Move 12px or less. Confirm the state and settle quickly.

06 / Accessibility

Reduced motion.

If a user prefers reduced motion, keep the same layout, hierarchy, and content. Remove animation duration, preserve final states, and avoid motion-only meaning.

Implementation rule: every parallax section needs a no-motion version that still reads as a finished composition. Do not make motion the only way to understand progress, validation, or page structure.
